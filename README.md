# Мультимодальный retrieval по диаграммам AI2D: CLIP baseline и графовый энкодер


Цель - построить систему сопоставления **изображений диаграмм** и **текстовых запросов** (question + correct answer) на датасете **AI2D** и оценить качество retrieval по метрикам **Mean Recall@K**.

Проект сравнивает:
1) **CLIP без дообучения** (zero-shot baseline),
2) **CLIP с дообучением** на парах (image–text),
3) **Графовый подход**: извлечение объектов (shape/OCR), построение графа, обучение **GraphEncoder + TextProj**.

---

## Постановка задачи
Дан набор пар *(I, T)*, где:
- **I** — изображение диаграммы,
- **T** — текст (вопрос + правильный ответ, либо другая выбранная текстовая схема).

Требуется обучить/настроить модель, которая отображает изображения и тексты в общее векторное пространство так, чтобы:
- для каждого текста **T** релевантное изображение **I** ранжировалось как можно выше,
- и наоборот: для каждого изображения **I** релевантный текст **T** ранжировался как можно выше.

---

## Метрики
Используются метрики retrieval:
- **Mean R@1** — доля случаев, когда релевантный элемент найден в Top-1,
- **Mean R@5** — доля случаев, когда релевантный элемент найден в Top-5,
- **Mean R@10** — доля случаев, когда релевантный элемент найден в Top-10.

> В зависимости от протокола возможно вычисление по парам (pair) или по группам (group). В ноутбуках использованы соответствующие варианты, а в README приведена итоговая сводная таблица по ключевым экспериментам.

---

## Результаты (сводная таблица)
| Подход | Mean R@1 | Mean R@5 | Mean R@10 |
|---|---:|---:|---:|
| CLIP (без дообуч.) | 0.0725 | 0.1857 | 0.2573 |
| CLIP (с дообучением) | 0.1708 | 0.3620 | 0.4744 |
| GraphEncoder + TextProj (граф + текст) | 0.2875 | 0.6225 | 0.7900 |
